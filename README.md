# 🍽️ UK Restaurant - Website Đặt Món Online

Website đặt món online UK Restaurant với slogan "Ăn no khỏi 'bàn'".

## 📋 Tổng quan

- **Công nghệ:** Next.js, Tailwind CSS, MongoDB
- **Loại:** Single Page Application (SPA)
- **Yêu cầu:** Responsive, tối ưu mobile, SEO friendly

## 🚀 Tính năng

### Khách hàng:
- Xem menu, filter theo danh mục
- Thêm món vào giỏ hàng
- Đặt món trực tiếp (không cần đăng nhập)
- Tra cứu đơn hàng bằng số điện thoại
- Đăng nhập/đăng ký (optional) để xem lịch sử

### Admin:
- Dashboard thống kê đơn hàng
- Quản lý đơn hàng, món ăn, danh mục
